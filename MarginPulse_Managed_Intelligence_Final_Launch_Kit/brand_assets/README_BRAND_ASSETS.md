# MarginPulse brand assets

Brand hierarchy: **MarginPulse** is the parent brand; **Managed Intelligence Reporting Service** is the service line.

The visual identity uses deep navy, teal and emerald green on white / pale mint backgrounds. The circular logo file intentionally excludes the prior GST / bank / ITC positioning from the managed-service badge.

Included:
- `MarginPulse_Managed_Intelligence_Logo.png` — full circular logo badge.
- `MarginPulse_Icon.png` — compact icon for profile / favicon use.

Do not stretch the logo, recolour it inconsistently or add the old financial-risk tagline to the managed-service sub-brand. Preserve clear space around the mark and use it on uncluttered backgrounds.
